# unknown-youth-site
UNKNOWN YOUTH
A simple multi-section website for UNKNOWN YOUTH, a Ghanaian streetwear brand — built as a WEBBO3 mini project.
About
The site introduces the brand, shows a piece from the current drop, and links out to the brand's social page. It's built with plain HTML and CSS — no frameworks, no build tools.
Sections
	•	Hero — heading and one-line intro to the brand
	•	About — the story behind UNKNOWN YOUTH
	•	Lookbook — a look at the current drop, with an image
	•	Connect — link out to the brand's X page
Built with
	•	HTML5
	•	CSS3 (custom stylesheet, no framework)
	•	Responsive layout — works down to phone screen widths
